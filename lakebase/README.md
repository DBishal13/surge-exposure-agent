# Lakebase - data layer

Loads the real precomputed output of
[DBishal13/surge-exposure](https://github.com/DBishal13/surge-exposure) —
7,717 buildings across 8 coastal regions, each scored 0-1 for storm-surge
exposure — into Lakebase (Databricks' managed Postgres). This is what the
agent's tools and the review app both read and write.

## Setup

1. In your Databricks workspace: **Compute > Lakebase > Create database instance**.
2. Grab the connection details and generate a Databricks personal access
   token to use as the password.
3. From the repo root: `cp .env.example .env` and fill in the values.
4. Apply the schema:
   ```
   psql "host=<LAKEBASE_HOST> port=5432 dbname=databricks_postgres user=<user> sslmode=require" -f lakebase/schema.sql
   ```
5. Install dependencies (from the repo root), regenerate the data (or use
   the `data/*.csv` already in this repo), and load it:
   ```
   pip install -r requirements.txt
   cd lakebase
   python prepare_data.py   # re-pulls the 8 regions from the source repo
   python -m dotenv run -- python load_data.py
   ```

## What's here

- `schema.sql` — `regions`, `buildings` (the precomputed exposure scores),
  `inspection_flags` (the one write path), `lookup_log` (agent usage
  tracking).
- `db.py` — the data-access layer: reads (region summaries, building
  lookups, high-exposure scans) and writes (inspection flags). Both
  `../app/app.py` and the logic behind `../agent/register_tools.sql`
  mirror these functions, so the human app and the agent never drift
  apart on what a "region summary" or "flag" means.
- `prepare_data.py` / `load_data.py` — pull real data from the source repo
  and load it into Lakebase.

## Data provenance

`data/regions.csv` and `data/buildings.csv` are generated by
`prepare_data.py` from the source repo's precomputed GeoJSON exports
(`docs/data/*.geojson`), themselves produced by that project's real
pipeline (NOAA SLOSH storm-surge rasters + Overture Maps building
footprints — see `../knowledge_base/docs/scoring_methodology.md`). This is
real pipeline output, not synthetic or hand-written data.

# Day 1 - Lakebase: Surge Exposure Advisor data layer

Loads the real precomputed output of
[DBishal13/surge-exposure](https://github.com/DBishal13/surge-exposure) —
7,717 buildings across 8 coastal regions, each scored 0-1 for storm-surge
exposure — into Lakebase, and a Streamlit app to review it.

## Setup

1. In your Databricks workspace: **Compute > Lakebase > Create database instance**.
2. Grab the connection details and generate a Databricks personal access
   token to use as the password.
3. `cp .env.example .env` and fill in the values.
4. Apply the schema:
   ```
   psql "host=<LAKEBASE_HOST> port=5432 dbname=databricks_postgres user=<user> sslmode=require" -f schema.sql
   ```
5. Install dependencies, regenerate the data (or use the `data/*.csv`
   already in this repo), and load it:
   ```
   pip install -r requirements.txt
   python prepare_data.py   # re-pulls the 8 regions from the source repo
   python -m dotenv run -- python load_data.py
   ```
6. Run the app:
   ```
   python -m dotenv run -- streamlit run app.py
   ```

## What this covers (Day 1 practical outcome)

- A schema (`schema.sql`) for real application data: `regions`,
  `buildings` (the precomputed exposure scores), `inspection_flags` (write
  path), `lookup_log` (agent usage tracking).
- A working data-access layer (`db.py`) with reads (region summaries,
  building lookups, high-exposure scans) and writes (inspection flags).
- A UI (`app.py`): browse regions, filter buildings by minimum exposure
  score, flag a building for follow-up inspection.

`db.py`'s functions are reused directly as the agent's tools in
`../day3-agent`.

## Data provenance

`data/regions.csv` and `data/buildings.csv` are generated by
`prepare_data.py` from the source repo's precomputed GeoJSON exports
(`docs/data/*.geojson`), which were themselves produced by that project's
real pipeline (NOAA SLOSH storm-surge rasters + Overture Maps building
footprints — see `../day2-vector-search/knowledge_docs/scoring_methodology.md`).
This is real pipeline output, not synthetic or hand-written data.
